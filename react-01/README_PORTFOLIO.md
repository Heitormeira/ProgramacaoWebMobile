# Portfólio Profissional - Heitor Meira

Um portfólio profissional moderno e minimalista desenvolvido com **Next.js 16.3.0** e **React 19.2.8**, apresentando o perfil, experiência, projetos e conhecimentos técnicos de Heitor Meira, estudante de Ciência da Computação na UNICAP.

## 🎯 Características

- ✨ **Design profissional e minimalista** com paleta: preto, branco, cinza e verde escuro
- 📱 **Totalmente responsivo** para desktop, tablet e celular
- ⚡ **Performance otimizada** com Next.js e Turbopack
- 🎨 **CSS Modules** para estilização organizada e escalável
- ♿ **Acessibilidade** com semântica HTML adequada
- 🚀 **SEO otimizado** com metadados dinâmicos

## 🚀 Como Executar

### Pré-requisitos
- Node.js 18+ 
- npm ou yarn

### Instalação

```bash
cd react-01
npm install
```

### Desenvolvimento

```bash
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.

### Build para Produção

```bash
npm run build
npm start
```
